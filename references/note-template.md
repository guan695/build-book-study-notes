# 通用学习笔记规则

不要套用固定目录。先判断知识类型、用户基础和学习目标，再选择最自然的讲解结构。

最低结构只有：

```markdown
# <知识点>

<按内容需要组织正文，自行命名小节>

## 来源

- B01 — *原书名*：[本地原书](../materials/B01-title.pdf)，[本次页段](../extracts/M01-B01-S01.pdf)。
```

正文可以按概念关系、问题推导、操作步骤、时间顺序或比较维度组织。定义、公式、例子、图表、易错点、练习和总结都属于可选内容，只在确实有助于当前学习目标时加入。

写作时遵守：

- 使用清晰中文，难度符合用户基础和目标。
- 讲清知识之间的关系，不堆砌术语或切出过多小标题。
- 数学推导、计算或操作流程需要足够步骤；纯概念或历史主题不强制加入例题和练习。
- 只使用实际阅读过的小 PDF，公式、图片和图表要查看原页。
- 主教材负责主线，补充书只填补缺口。
- 来源保持简短，不写检索过程、哈希或内部清单。
