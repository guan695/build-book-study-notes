# 学习笔记模板

笔记写给学习者，只保留学习内容和简短来源。

```markdown
# <学习主题>

用几句话说明本次要解决的问题，以及学完能做什么。

## 核心内容

按概念依赖关系讲解。每个核心概念说明：直观含义、定义或公式、使用方法。

## 完整例题

至少给出一道可以独立复算的例题，不跳过关键步骤。

## 易错点

列出常见错误、错误原因和检查方法。

## 练习与答案

给出 3–5 道练习，并附必要的解答步骤。

## 来源

- B01 — *原书名*：[本地原书](materials/B01-title.pdf)，[本次页段](extracts/B01-S01.pdf)。
```

## 写作要求

- 使用清晰中文，难度符合用户确认的基础和目标。
- 一份笔记只讲一个完整模块，不堆砌术语。
- 只使用实际阅读过的小 PDF；公式、图片和图表要查看原页。
- 主教材负责讲解主线，补充书只填补缺口。
- 来源保持简短，不写检索过程、哈希或内部清单。
- 如果解释空泛、例题跳步或重要结论找不到出处，先重写再交付。
